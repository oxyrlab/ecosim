# Organs

An **Organ** (`src/body/organs/`) is a registered physical body part descriptor (`OrganDef`) specifying a `defaultShape`, `massDensity` (`kg/m^2`), `sensorSlots`, and `actuatorSlot`.

Built-in organs (`body-core`, `eye`, `nose`, `mouth`) are listed in [docs/catalog/organs.md](../catalog/organs.md). To add a new organ, see [guides/add-organ.md](../guides/add-organ.md).
