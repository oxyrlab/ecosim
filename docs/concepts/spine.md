# Spine

A **Spine** (`src/spine/`) translates high-level brain motor patterns (`move.forward`, `move.turn`, `action.bite`) into concrete actuator commands (`left.power`, `right.power`, `rotator.turn`, `mouth.bite`) and optional low-level reflexes.

The generic `differential-drive` spine is listed in [docs/catalog/brain-modules.md](../catalog/brain-modules.md#spines).
